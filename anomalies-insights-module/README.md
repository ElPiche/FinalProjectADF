# ES

Módulo de información encargado de crear indices de anomalías en elasticsearch, insertar documentos en el mismo,
configurar tableros de visualización de información de manera automática en Kibana y notificación de usuarios vía email.

# EN

Insights module responsible for creating anomaly indexes in Elasticsearch, inserting documents into it,
automatically configuring information visualization dashboards in Kibana, and notifying users via email.
