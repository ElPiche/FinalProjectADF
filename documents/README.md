# Project Documentation

This folder contains all the project documentation organized by module.

Structure:
- mcp/        : KB-MCP (documentation for Model Context Protocol tools and server)
- dispatcher/ : MotorDA/Dispatcher (algorithm implementations, orchestrator)
- extractor/  : ETL (Java) extractor documentation
- general/    : Cross-cutting docs (deployment, tests, fire tests)
- historic/   : Archived or superseded documentation

Each module is subdivided into:
- guides/          : How-tos and user-friendly implementation guides
- reports/         : Test results and session notes
- plans/           : Roadmaps and implementation plans
- specifications/  : High-level specs and architecture docs

Guidelines:
- Keep only current, final, and relevant docs in their module.
- Move drafts, intermediate runs, or older specs to the historic folder.
- The `historic/` folder is a record and should not be changed except for archival updates.
